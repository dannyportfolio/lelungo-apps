# ADR 0002: Repository is the source of truth

Status: Accepted

## Context
Multiple humans and agents must continue work without private conversational memory.

## Decision
Architecture, specifications, operations, decisions, and handoffs live in versioned repository files.

## Consequences
Documentation updates are part of definition of done and stale docs are defects.

## Rejected Alternatives
Chat-only decisions, external vector memory as authority, and undocumented conventions.
