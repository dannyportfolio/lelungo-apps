# Incident response

1. Confirm impact, severity, tenants, and first known time.
2. Contain without destroying evidence: revoke compromised credentials, disable a route/feature, or stop writes.
3. Preserve sanitized logs, deployment/migration IDs, and audit records.
4. Mitigate using the rollback runbook; communicate facts, not assumptions.
5. Verify tenant isolation, authentication, data integrity, and critical flows.
6. Recover gradually and monitor.
7. Write a blameless review with root cause, timeline, corrective controls, owner, and due date.

Never paste secrets or unrestricted personal/payment data into tickets, chat, or AI tools.
