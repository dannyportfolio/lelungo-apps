# Testing

- Unit: `npm run test` for database-free domain rules, parsing, permissions, validation, and adapter contracts.
- Integration: set `TEST_DATABASE_URL` to a dedicated disposable PostgreSQL and run `npm run test:integration`. Preflight rejects a missing/non-PostgreSQL URL, a database name without a standalone test marker, or the same normalized target as `DATABASE_URL`. Global setup applies all committed migrations. The Phase 2 suite verifies catalog/owner-scope results, same-Tenant role constraints, duplicate slugs, cross-Tenant Property grants, one-winner optimistic concurrency, atomic audit rollback, and named schema constraints/indexes/foreign keys. Cleanup targets only exact test-owned records. Never point it at staging, production, or a normal development database.
- E2E: start/target the application and run `npm run test:e2e`; set `BASE_URL` for a non-default port. The staff spec runs with `npm run test:e2e -- tests/e2e/staff-authentication.spec.ts` and its built-in deterministic mode requires the same validated, already migrated disposable `TEST_DATABASE_URL` used by integration tests. It covers unauthenticated and no-membership denial plus Phase 2 missing-permission denial, selected Property A versus B, invalid timezone and authorized creation, stale expected-version conflict, and minimum-field scope administration. Fixtures remove only their generated records. Playwright uses a local fake Supabase Auth boundary by default; `E2E_SUPABASE_URL` can override it, in which case deterministic local fixtures may be skipped. Set `PLAYWRIGHT_USE_PRODUCTION_SERVER=true` only after `npm run build` when the test should exercise `next start`; otherwise the harness uses `next dev`. Neither mode proves live production-provider behavior.
- Static/specification: `npm run format:check`, `npm run lint`, `npm run typecheck`, `npm run prisma:validate`, and `npm run spec:validate`.
- Production compilation: `npm run build`.

Record the exact command, exit code, failures, retries, and skipped layers. Never call a retry-only flaky result unconditionally healthy; retain artifacts and fix synchronization.
